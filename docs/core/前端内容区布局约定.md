# 前端内容区布局约定

> 适用范围：所有以表格为主体的列表/管理页（前台与 /admin 后台通用）。以下为自包含规则，勿以某个现有页面为参照——参考实现可能重构或删除，以本文档为准。

## 规则

1. **外壳**：`Card` 默认尺寸（禁 `size="small"`），`title` 放页面名；有多视图时在 title 里加 `Segmented` 切换——**禁 Card 内套 `Tabs`**（Tabs 的边距/下划线与 Card 头部叠加后视觉层级混乱）。
2. **操作按钮一律放 Card `extra`**：默认大小、图标+文字——`刷新`（`ReloadOutlined`）、主操作 `新建xx`（`type="primary"` + `PlusOutlined`）。多视图时 extra 随视图切换（只显示当前视图可用的操作），禁把工具栏放在 body 里。
3. **页面说明文字**：body 顶部 `Typography.Paragraph type="secondary"` 一句话说明这个页面管什么，不进工具栏。
4. **表格**：默认密度（禁 `size="small"`），`pagination={false}`（服务端真分页除外）；行内操作用小号普通按钮（查看/管理），`danger` 仅用于删除；单条记录的成套操作（启用/禁用/升级/删除等）收进一个「管理」入口开 `Drawer` 承载，不在行内堆按钮。
5. **空态**：`locale.emptyText` 或 `Empty` 里给出下一步引导（如「新建xx」按钮），不只写「暂无数据」。

## 骨架

```tsx
<Card
  title={
    <Space size={12}>
      <span>页面名</span>
      <Segmented value={view} onChange={setView} options={[...]} />  {/* 单视图页面省略 */}
    </Space>
  }
  extra={
    <Space>
      <Button icon={<ReloadOutlined />} onClick={load}>刷新</Button>
      <Button type="primary" icon={<PlusOutlined />} onClick={onCreate}>新建xx</Button>
    </Space>
  }
>
  <Typography.Paragraph type="secondary">一句话说明这个页面管什么。</Typography.Paragraph>
  <Table rowKey="id" loading={loading} columns={columns} dataSource={rows} pagination={false} />
</Card>
```
